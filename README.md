# Бизнес-Сити — 3D 🏙️

Полноценная 3D-версия классической «Монополии» в виде **одного HTML-файла** — без сборки, без сервера, без установки. Просто откройте файл в браузере.

## 📦 Файлы проекта

| Файл | Описание |
|------|----------|
| `монополия полный код.html` | Вся игра: разметка, стили и логика в одном файле (~3800 строк) |

## 🚀 Запуск

1. Скачайте / клонируйте репозиторий.
2. Откройте `монополия полный код.html` в любом современном браузере (Chrome, Firefox, Edge, Safari).

> **Требуется интернет-соединение**: Three.js (r128) и шрифт Rubik подгружаются с CDN (jsdelivr).

Игра оптимизирована и для десктопа, и для мобильных устройств (сенсорное управление камерой, адаптивная вёрстка).

## 🎮 Об игре

**Цель** — остаться последним непобанкротившимся игроком. Стартовый капитал — **$1500**. Лобби поддерживает **2–4 игрока** (человек + боты).

### Основные механики

- 🎲 **Классическое поле**: покупка клеток, аренда, карты «Шанс», тюрьма, налоги, аукционы.
- 🏗️ **Застройка**: дома → отели → спецпостройки (небоскрёб ×2 ренты, бизнес-центр, депо).
- 🤖 **Боты трёх уровней**: Лёгкий, Средний, Сложный — покупают, строят, торгуются и предлагают сделки. Имеют «Агрессию» и «Память» на отказы в сделках.
- 📈 **Биржа**: 4 корпорации, цены растут от активности на поле, дивиденды на проходе GO, можно основать свою компанию за $800.
- 💰 **Ипотека и тендеры**: заложайте клетки и боритесь за чужую недвижимость.
- 🏆 **Карьера**: за победы начисляется Репутация — тратится на перки старта и новые цвета фишек.
- ⚙️ **Настраиваемые правила**: стартовый капитал, ставки рент, ипотека и другие параметры партий.
- 📊 **Аналитика**: тепловая карта опасных клеток соперников и ваших монополий; статистика игроков.
- 🔊 **Звук**: процедурные звуковые эффекты на Web Audio API (без внешних файлов).
- 🎥 **3D-сцена на Three.js**: кинематографичная камера, крупный план кубиков, интерактивные клетки и фишки.

### Управление

- **Drag** — вращение камеры
- **2 пальца / Shift+drag** — панорама и зум
- **Тап по клетке** — доступные действия
- **Тап по игроку** — профиль и статистика

## 💾 Сохранения

Прогресс хранится в `localStorage`:
- Именные слоты **1–3** для ручных сохранений;
- Служебный слот **0** — автосейв (защита от случайного закрытия);
- «Выйти без сохранения» стирает слот 0.

Также через localStorage сохраняются наборы правил (`mono_sets`) и кастомные настройки (`mono_custom`).

## 🛠️ Технологии

- **HTML5 / CSS / Vanilla JavaScript** — всё в одном файле
- **[Three.js r128](https://threejs.org/)** — 3D-рендеринг (через CDN)
- **Web Audio API** — процедурные звуки
- **Fontsource / Rubik** — шрифт (через CDN)
